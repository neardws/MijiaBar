FAQ
Questions, answered.

    

      
What do I need?
macOS 14 Sonoma or later on Apple Silicon or Intel, and a Xiaomi account with devices in Mi Home.

      
Is it safe to install?
Yes. Every build is signed with a Developer ID and notarized by Apple, and the source code is on GitHub under the MIT license.

      
Does it work away from home?
Controls fall back to the Xiaomi cloud automatically. Live camera view only works on your home network.

      
How do updates work?
MijiaBar checks for updates on its own from 0.1.9 on. If you're on 0.1.8 or earlier, download this version once.
